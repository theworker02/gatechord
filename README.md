# gatechord

Gate structured JSON chord payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/gatechord/

## Install / run

```bash
git clone https://github.com/theworker02/gatechord.git
cd gatechord
node src/cli.js
node --test
```
